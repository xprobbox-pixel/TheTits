# Factory preset guide — 0.3.0

Increase the main dial to transform the sound. Early, mid and late macro behavior varies deliberately. Existing saved DAW states keep their original processing until a factory preset is selected.

| Preset | Chain | Character |
|---|---|---|
| Disco Lift (Jiggle Nipples in the UI) | Flanger → EQ → Reverb | Wide jet sweep with resonant positive-feedback flanging, a bright shelf and a small room; no high-pass or echo. |
| Jackin Pressure | Gate → Drive | Hard eighth-note chopping into crunchy drive. A rhythmic dry-bus transformation without filter or delay. |
| Hands Up Wash | High-pass → Reverb | A resonant high-pass sweep dissolves into an almost fully wet, bright large room; no echo. |
| Late Night Echo | Tape echo | An exposed dotted-eighth ping-pong tape throw, with dark feedback and no filter sweep or room. |
| Snare Ladder | Loop/stutter → Drive | Captured forward slices accelerate from a quarter note to a 1/128-note buzz, with increasing grit. |
| Digital Meltdown | Crusher | Full-band four-bit, 1.4 kHz sample-and-hold destruction. No high-pass, delay or reverb hides the aliasing. |
| Warehouse Siren | Siren → Flanger → Delay | A rising octave siren passes through resonant flanging and quarter-note repeats. |
| White Heat | Noise → Reverb | A bright white-noise ascent spreads into a huge low-damping room; no high-pass or discrete echo. |
| Vinyl Tunnel | Phaser → Band-pass | A deep stereo four-stage phaser with feedback, followed by a slowly narrowing band-pass corridor. |
| Reverse Tease | Loop/stutter → Reverb | A held reversed eighth-note fragment takes over early, then blooms into a short dark room. |
| Pump It Up | Gate → Autopan | Sixteenth-note hard gating alternates with fast stereo movement. No tonal sweep or time effect. |
| The Big Finish | Low-pass → Crusher → Delay → Reverb → Loop/stutter → Flanger | Six stages: low-pass closure, five-bit crush, ping-pong delay, huge reverb, accelerating stutter and jet flanging. |
| Velvet Balcony | Low-pass | A smooth, deep low-pass descent to 220 Hz. Pure filter movement without wash, echo or modulation. |
| Vocal Comet | Delay → Reverb | A full half-note stereo throw rings into a bright large room; the dry low end is not swept away. |
| Rooftop Shimmer | Chorus → EQ → Reverb | Deep moving chorus, air shelf and restrained ambience. No high-pass, stutter or repeating echo. |
| Bassline Orbit | Flanger → Low-pass | Negative-polarity comb sweeps orbit the stereo field while a gentle low-pass darkens the top. |
| Percussion Staircase | Loop/stutter → Gate | A whole quarter-note loop locks in early and stays at the same length while triplet gating intensifies. |
| Neon Exit | Crusher → Low-pass → Drive → Tape echo | Eight-bit telephone-rate crunch closes through a resonant low-pass into saturated short mono tape repeats. |
| Pink Champagne | Gain / width → Noise → Autopan → Reverb | The input recedes beneath a descending low pink-noise swell, slow stereo movement and a small dark room. |
| Dub Elevator | EQ → Tape echo → Phaser | Bass shelf removal feeds long dotted-quarter tape feedback, then a slow resonant phase sweep with a compensated wet return. |
| Midnight Pendulum | Autopan → Delay → Phaser | Full-width triplet panning with triplet-quarter clean repeats and fast phase movement. |
| Starlight Call | Siren → Reverb | A descending C5 siren with fast vibrato floats above long dark reverb; no discrete echo. |
| Filter Confetti | High-pass | Pure resonant 24 dB/octave high-pass rise to 6 kHz. No echo, modulation, bit reduction or reverb. |
| Last Train Home | Low-pass → Reverb → Loop/stutter | A deep low-pass descent smears into an almost fully wet dark hall, with a late held reverse sixteenth-note loop. |
